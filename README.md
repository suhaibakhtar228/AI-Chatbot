# AI Buddy - AI Chatbot

AI Buddy is a simple AI-powered chatbot developed using HTML, CSS, and JavaScript. It uses the Google Gemini API to generate responses to user queries.

## Features

- Simple and user-friendly interface
- AI-powered responses using Gemini API
- Chat history during the current session
- Responsive design
- Dark theme with blue and green accents

## Technologies Used

- HTML
- CSS
- JavaScript
- Google Gemini API

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Configure your Gemini API key for local testing.
4. Open `index.html` using Live Server.

**Note:** This project currently uses a frontend API integration for learning purposes. Do not publish a real API key in the source code.
